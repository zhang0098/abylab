abylab

极简主义的 DeepSeek harness。装完就是一个可执行文件，没有依赖，启动飞快，开源免费。

快速开始

  1. 在你的终端中执行下面语句：

    /bin/bash -c "$(curl -fsSL https://abylab.ai/install.sh)"

    支持 Linux · macOS · 安装到 ~/.local/bin/abylab

  2. 去 platform.deepseek.com 取一个 API Key。

  3. 在终端里运行 abylab，然后在输入框里登录一次：

    /login sk-xxxxxxxx

  4. 直接输入你的要求，开始工作。

想从源码构建：cargo build --release。安装脚本支持 --bin-dir、--version、--no-path、--path-file、--help。

特性

一个文件

没有 Node、没有 Python、没有依赖目录、没有后台进程。发布构建约 11 MB，压缩包约 4.9 MB，abylab --version 冷启动约 2 ms。

一个进程

流式输出、工具执行、会话持久化都发生在同一个进程里：没有 IPC 往返，没有 GC 停顿，没有额外的 runtime。

凭证只落在你手里

abylab 不读 DEEPSEEK_API_KEY 或任何环境变量。密钥由 /login 写入 ~/.abylab/.credentials.yaml（0600，仅属主可读）。

终端原生

九个内置主题包、鼠标滚动与拖拽复制、@ 文件提及、图片粘贴，以及 read-only / workspace-write / danger-full-access 三档权限。

开源免费

MIT 许可，源码全在 GitHub：读、改、自己 cargo build --release 都行。不用注册账号，也没有付费档。

里面是什么

crates/abycoreagent SDK：Agent、会话快照、工具
crates/abylab-backendabycore Agent 驱动：命令 ⇄ Agent::run，hooks → 权限询问
crates/abylab-tui终端画布：输入卡片、markdown、主题包、@ 文件、图片缩略图

实现细节（工作区指令、上下文压缩、会话持久化、目标轮次）见 TECH.md。

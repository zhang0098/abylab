01 / GET STARTED

快速开始

从安装到第一句对话，
只需这几步。

>_

  1. 安装 abylab

    在你的终端中执行下面语句：

    curl -fsSL https://abylab.ai/install.sh | bash

    支持 Linux · macOS · 安装到 ~/.local/bin/abylab

  2. 准备 API Key

    去 platform.deepseek.com 取一个 API Key。

  3. 启动，然后登录

    在终端里运行 abylab，然后在输入框里登录一次：

    /login sk-xxxxxxxx

  4. 开始你的第一个任务

    直接输入你的要求，开始工作。

想从源码构建：cargo build --release。安装脚本支持 --bin-dir、--version、--no-path、--path-file、--help。

想卸载 abylab：运行 abylab --uninstall。

01 / BINARY

一个文件

没有 Node、没有 Python、没有依赖目录、没有后台进程。发布构建约 11 MB，压缩包约 4.9 MB，abylab --version 冷启动约 2 ms。

RustLinux + macOS~11 MB
02 / RUNTIME

一个进程

流式输出、工具执行、会话持久化都发生在同一个进程里：没有 IPC 往返，没有 GC 停顿，没有额外的 runtime。

03 / PRIVACY

凭证只落在你手里

abylab 不从 DEEPSEEK_API_KEY 等环境变量读取凭据。密钥由 /login 写入 ~/.abylab/.credentials.yaml（0600，仅属主可读）。

04 / EXPERIENCE

终端原生

九个内置主题包、鼠标滚动与拖拽复制、@ 文件提及、图片粘贴，以及 read-only / workspace-write / danger-full-access 三档权限。

05 / OPEN SOURCE

开源免费

MIT 许可，源码全在 GitHub：读、改、自己 cargo build --release 都行。不用注册账号，也没有付费档。
